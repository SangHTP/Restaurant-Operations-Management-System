# Restaurant Operations Management System — Modular Prototype

React + Vite + Tailwind CSS prototype for the FPT Restaurant Operations Management System.

## src structure
- api: ASP.NET Core API placeholders
- assets: images/icons
- components: reusable UI components
- data: mock data
- layouts: shared page layouts
- pages: pages grouped by actor
- routes: role/path configuration
- App.jsx / main.jsx: application entry

## Run
npm install
npm run dev

The prototype is frontend-only and uses mock data. It can later connect to the ASP.NET Core Web API.
